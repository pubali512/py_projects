# Kiva Lending Patterns

Exploratory data analysis of historical Kiva loan records, covering data cleaning, three assessed visualizations, and two interactive Dash dashboards.

## Project Structure

```
eda_story/
├── data_abschlussprojekt.csv   # Raw dataset (# separator, ~670k rows)
├── kiva_cleaned.csv            # Cleaned dataset (generated by the notebook)
├── kiva_eda_dash.ipynb         # Single combined notebook
└── README.md
```

## Notebook: `kiva_eda_dash.ipynb`

The notebook runs the full pipeline in four sections:

| Section | Content |
|---|---|
| **1 -- Setup** | Package installation, imports, file path definitions, port cleanup |
| **2 -- Data Cleaning** | 13 cleaning steps: whitespace, duplicates, missing values, validation, `funding_gap` derivation |
| **3 -- Assessed Visualizations** | Three charts (see below) |
| **4 -- Dashboard: Sector Lens** | Interactive Dash app (port 8051) |

### Assessed Visualizations

1. **Loan Count by Country** -- horizontal bar chart showing the top N countries by number of loans
2. **Sector Distribution for Top N Countries** -- 100% stacked bar; sectors sorted by global share
3. **Funding Completeness by Sector** -- bubble scatter; Y = % fully funded, X = loan count, bubble size = median loan amount, color = funding level bin

### Dashboard: Kiva Sector Lens (port 8051)

- Sector dropdown (default: Overall -- all sectors combined)
- Numeric input for top N countries (default: 15)
- Scatter chart: loan count vs median loan size; bubble area = total funded amount; color = dominant repayment interval

## Setup

Run the first cell of the notebook to install all dependencies:

```bash
pip install --upgrade pandas numpy seaborn plotly dash psutil
```

## Data

The raw file uses `#` as the column separator. Key columns: `funded_amount`, `loan_amount`, `sector`, `country`, `repayment_interval`, `term_in_months`, `borrower_genders`.

`kiva_cleaned.csv` is produced by Section 2 of the notebook and contains an additional `funding_gap` column (`loan_amount - funded_amount`).
