## Relational Schema (abbreviated)

```
supplier(supplier_id PK, supplier_name, city, country)

category(category_id PK, category_name, parent_category_id FK→category)

product(product_id PK, product_name, list_price, colour, material,
        category_id FK→category, supplier_id FK→supplier)

customer(customer_id PK, first_name, last_name, email, street_address,
         postal_code, city, federal_state, customer_since)

order_header(order_id PK, order_date, payment_method, shipping_cost,
             customer_id FK→customer)

order_line(order_line_id PK, quantity, unit_price, discount,
           order_id FK→order_header, product_id FK→product)
```

## Normal Form Verification

**1NF** — All tables: atomic attributes, no repeating groups, single-column PKs. ✅

**2NF** — No partial dependencies (all non-key columns depend on full PK, not part of it). Only `order_line` has composite logical key order_id + product_id, but PK is surrogate `order_line_id` — no partial dependencies. ✅

**3NF** — Check transitive dependencies:

| Table | Check | Result |
|---|---|---|
| `customer` | postal_code → city? | city stored independently; not derived from PLZ in Business DB. ✅ |
| `order_line` | unit_price from product? | unit_price stored per line (allows dynamic pricing ≠ list_price). ✅ |
| `product` | category attributes? | category name in separate `category` table (not in product). ✅ |
| `order_header` | customer attributes? | Only FK stored, not duplicated. ✅ |

**All six tables are in 3NF.** ✅

## Data Import Description

Data generated by `python/data_gen/generate_data.py` (Faker `de_DE` locale):

| Entity | Generation method |
|---|---|
| `supplier` | 20 hardcoded entries (10 Germany, 10 neighboring countries) |
| `category` | 5 top-level + 10 sub-categories, hardcoded tree |
| `product` | 120 names from templates × adjectives; random price (€50–€2,500) |
| `customer` | Faker names; email derived from name; PLZ/city from `data/plz_city_mapping.csv` |
| `order_header` | Random date 2024-01-01–2025-12-31; weighted payment method |
| `order_line` | 1–5 lines/order; unit_price = list_price ±10%; discount 80% zero |

PLZ-city mapping: 1,150 real postal codes for 75 German cities fetched from OpenPLZ API — stored in `data/plz_city_mapping.csv`.
